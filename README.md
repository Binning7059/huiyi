# 回译训练句库

用回译练英语造句能力：按句型框架间隔复习，题材覆盖雅思和 PTE 常见话题，难度 B1–B2。

在线使用：https://binning7059.github.io/huiyi/

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 练习页面：今日复习、句库（在这里读句子、加入学习库）、进度统计 |
| `bank.json` | 句库数据：句子、搭配、翻译技巧标签 |
| `tools/check_bank.py` | 句库检查脚本，每次更新句库前运行 |
| `CLAUDE.md` | 维护规则（给 Claude 和你自己看） |

## 部署（只需做一次）

仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`，保存。一两分钟后即可访问上面的网址。之后每次提交，网站都会自动更新。

## 日常更新

- **加句子 / 改句子**：只改 `bank.json`。进度不受影响，前提是不删除、不改名已有的句子 ID 和搭配 ID。
- **检查**：本地运行 `python tools/check_bank.py`，没有 ERROR 再提交。
- **生效时间**：提交后约 1 分钟网站更新，打开页面刷新即可。

## 进度保存

进度保存在浏览器本地。换设备或清理浏览器数据之前，请在「进度」页导出备份，到新设备上再导入。

直接双击打开 `index.html` 无法载入句库（浏览器禁止本地页面读取文件），请通过网址访问，或在本目录运行 `python -m http.server` 后打开 `http://localhost:8000`。
